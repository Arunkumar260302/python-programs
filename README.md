#Netfix content analysis(EDA)
##Overview
Exploratory Data analysis on Netflix's content catalog to uncover trends in content type,Release year, genre distribution,rating,country wise production
##Datset
-Source: netflix_titles.csv
-Records: 7,787 Netflix Titles(Movies,TV shows)
##Tools&libraries
-python
-pandas-data cleaning&manipulation
-Matbotlib-data visualization
##Key Insights
-movies make up a significatantly larger share of netflix's catalog compared to TV shows
-Documentaries,stand-up Comedy,and international movies are among the top genres
-content additions peaked in recent years(2018-2020)
